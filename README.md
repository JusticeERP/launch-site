# 🚀 Launch Page (launch_page)

A blazing-fast, modern, dark-mode static launch page designed for software products, startups, and developer tools. Built with pure HTML, Tailwind CSS, and FontAwesome icons.

## Features

- **Zero-Dependency Styling:** Powered entirely via Tailwind CSS CDN.
- **Responsive & Fluid:** Fully optimized for mobile, tablet, and desktop screens.
- **Interactive Mockup:** Includes a simulated live workspace dashboard preview.
- **Waitlist Form:** Ready to capture early adopter leads.

## Quick Start

1. Clone the repository:

```bash
git clone https://github.com/yourusername/launch_page.git
cd launch_page
```

2. Open `index.html` directly in your browser or serve it locally:

```bash
npx serve .
```

## Deployment

Deploy instantly and for free using:

- **Cloudflare Pages** (Point to root directory)
- **Vercel** (`vercel --prod`)
- **GitHub Pages** (Enable via repository settings)
